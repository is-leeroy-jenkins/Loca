LOCAL INSTALLATION

From download to local inference.

Loca is intentionally not a cloud inference service. The Azure portal gets the software to the user; Python, Streamlit, llama.cpp, the SQLite assets, and GGUF inference run on the user's system.

01

Download Loca

Download the repository ZIP or clone the GitHub repository.

02

Create a Python environment

Use Python 3.11, create a virtual environment, then install requirements.txt.

03

Download a GGUF model

Use one of the model cards above to open its Hugging Face repository and select a GGUF file.

04

Set the model path

Set the matching environment variable, such as BRO_LLM_PATH, to the downloaded GGUF path.

05

Launch Loca

Run streamlit run app.py and use the application entirely on the local workstation.
